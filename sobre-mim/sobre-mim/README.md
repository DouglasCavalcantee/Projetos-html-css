# 👤 Página Sobre Mim

Projeto desenvolvido com HTML5 e CSS3 com foco em layout moderno, tema dark e responsividade.

## 🔥 Funcionalidades

- Design dark moderno
- Layout responsivo
- Foto de perfil estilizada
- Botões com links externos para GitHub e LinkedIn
- Organização visual voltada para apresentação profissional

## 🛠 Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Responsividade

## 📌 Objetivo

Praticar estruturação de páginas, estilização com CSS e criação de uma página pessoal para portfólio.
